# NFL RosterWire

Deterministic weekly roster transaction planner for **SOFTDRINK NFL 2K28 / ESPN NFL 2K5**.

The tool compares an exported Mod Studio roster CSV to a current NFL roster snapshot, proposes signings/releases/team moves, and stages **approved team-only changes** in a separate CSV. No AI decisions or ratings adjustments are involved in v1.

**Status:** experimental. Mod Studio re-import and xemu save loading are not yet validated. Do **not** overwrite your working save.

See the project README and source files after the initial implementation is added.

**Do not commit game roster exports, save files, or downloaded NFL data.**
